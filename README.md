# Five Failure Regimes in Dark-Matter Light Probes

## An Open-Source Pre-Result Demonstration Protocol

This repository contains the current machine-backed release of a falsifiable dark-matter light-probe experiment built around a five-way structural first-break classification.

The experiment asks whether independently warranted dark-matter physical routes can be classified upstream of a held-out light result as Dissolution, Shear, Drift, Echo, or Lock, and whether physically instantiated branches can generate preregistered source-to-light predictions that survive ordinary gravitational propagation, measurement, and comparison with a strong ordinary-physics baseline.

The number five refers to structural first-break classes. It does not predict five observable image morphologies.

The protocol is intentionally pre-result. It does not report a completed simulation campaign, astronomical execution, or empirical validation of Structural Flow. It specifies an open execution architecture that another group can instantiate, freeze, run, audit, and attempt to falsify.

## Scientific posture

The information order is:

dark-matter physical state  
→ registered route and primary scale  
→ intrinsic route-success test  
→ first-break classification  
→ frozen source prediction  
→ ordinary gravitational forward model  
→ held-out light prediction  
→ measurement and reconstruction  
→ comparison with the preregistered ordinary-physics baseline  
→ result adjudication

Structural Flow supplies the candidate first-break classification and experimental organization. It does not replace the dark-matter physics, gravitational field equations, or propagation law for light.

Lower-level failures remain lower-level failures. Search, physicalization, source, light, measurement, and predictive-utility outcomes do not automatically become foundational novelty.

A replicated structural residual can place pressure on the five-regime closure only after the registered ordinary explanations, state-completeness audit, replication requirements, and foundational-newness gates have been traversed.
